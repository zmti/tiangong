# TianGong 桌面端 UI 重构方案

## 设计目标
**合理 · 高效 · 现代 · 友好**

---

## 一、现状问题分析

### 1.1 导航问题
| 问题 | 影响 |
|------|------|
| 12个图标挤在58px侧栏 | 视觉拥挤，缺乏分组层次 |
| 图标无标签 | 新用户学习成本高 |
| 无激活状态反馈 | 用户迷失位置 |

### 1.2 布局问题
| 问题 | 影响 |
|------|------|
| 10个侧边面板平铺 | 功能入口分散 |
| 头部5个控件堆砌 | 信息密度过高 |
| 工具栏5个按钮 | 操作效率低 |

### 1.3 视觉问题
| 问题 | 影响 |
|------|------|
| Welcome卡片无层次 | 第一印象弱 |
| 消息气泡样式单调 | 缺乏情感化设计 |
| 动画过于简单 | 交互体验不够流畅 |

## 二、重构方案

### 2.1 布局重构（三栏式设计）

```
┌─────────────────────────────────────────────────────────────────┐
│  Logo  │  🏠 对话    │                                              │
│        │  📚 知识库  │         主内容区域                          │
│  导航  │  🧠 记忆    │            │                               │
│  区域  │  📋 待办    │         [ 聊天/知识库/记忆... ]             │
│  (68px)│  ⚙️ 设置    │            │                               │
│        │             │         [ 输入框 + 工具栏 ]                 │
│  [🌙]  │             │            │                               │
└────────┴────────────┴────────────┴───────────────────────────────┘
     ↑             ↑               ↑
   导航栏        会话列表         主内容区
   悬停展开      260px            自适应
```

### 2.2 导航优化

**设计决策：**
- 默认显示图标（节省空间）
- 悬停时展开显示标签
- 激活状态左侧渐变高亮条
- 平滑过渡动画（200ms）

**CSS 实现：**
```css
.nav-sidebar:hover { width: 200px; }

.nav-sidebar:hover .nav-item-label {
  opacity: 1;
  transform: translateX(0);
}
```

### 2.3 消息气泡增强

**用户消息：**
- 渐变紫色背景
- 右对齐布局
- 圆角差异化（右下角小圆角）

**助手消息：**
- 白色卡片 + 左侧边框
- 悬停显示操作按钮
- 平滑入场动画

**操作按钮：**
- 复制、回复、重新生成
- 悬停显示（避免视觉干扰）
- 圆角胶囊样式

### 2.4 输入框优化

**设计要点：**
- 自动高度调整（最小60px，最大200px）
- 聚焦时边框高亮 + 紫色阴影
- 工具按钮悬停放大效果
- 快捷键提示栏（响应式显示）

**交互细节：**
```css
.composer:focus-within {
  border-color: var(--primary);
  box-shadow: 0 0 0 3px var(--primary-soft);
}
```

## 三、视觉设计系统

### 3.1 色彩系统

| 类别 | 颜色值 | 用途 |
|------|--------|------|
| 主色 | `#7c5cfc` | 品牌、强调、按钮 |
| 辅助色 | `#38bdf8` | 链接、提示 |
| 成功 | `#10b981` | 完成状态、正向反馈 |
| 警告 | `#f59e0b` | 风险提示 |
| 错误 | `#ef4444` | 错误状态、删除操作 |
| 信息 | `#3b82f6` | 一般提示 |

### 3.2 背景系统

| 层级 | 颜色值 | 用途 |
|------|--------|------|
| Base | `#f0f2f8` | 页面背景 |
| Surface | `#ffffff` | 卡片、面板 |
| Elevated | `#f8f9fd` | 悬浮层、输入框 |
| Hover | `rgba(124,92,252,0.04)` | 悬停状态 |

### 3.3 文字系统

| 层级 | 颜色值 | 字号 | 用途 |
|------|--------|------|------|
| Primary | `#0f172a` | 14px | 主标题、内容 |
| Secondary | `#475569` | 13px | 次级文字 |
| Muted | `#94a3b8` | 12px | 提示文字 |
| Faint | `#cbd5e1` | 11px | 辅助文字 |

### 3.4 圆角系统

| 变量 | 值 | 用途 |
|------|-----|------|
| `--radius-sm` | `6px` | 小控件、标签 |
| `--radius-md` | `10px` | 卡片、按钮 |
| `--radius-lg` | `16px` | 面板、消息 |
| `--radius-xl` | `24px` | 大容器、Welcome卡片 |
| `--radius-full` | `9999px` | 胶囊按钮、头像 |

### 3.5 阴影系统

| 层级 | 值 | 用途 |
|------|-----|------|
| `--shadow-xs` | `0 1px 2px rgba(..., 0.04)` | 极轻悬浮 |
| `--shadow-sm` | `0 2px 8px rgba(..., 0.06)` | 卡片阴影 |
| `--shadow-md` | `0 4px 16px rgba(..., 0.08)` | 面板阴影 |
| `--shadow-lg` | `0 8px 32px rgba(..., 0.10)` | 模态框阴影 |
| `--shadow-xl` | `0 16px 48px rgba(..., 0.12)` | 重要浮层 |

## 四、动效系统

### 4.1 动画时长

| 类别 | 时长 | 用途 |
|------|------|------|
| Fast | `150ms` | 按钮点击、图标切换 |
| Normal | `200ms` | 面板展开、消息显示 |
| Slow | `300ms` | 页面切换、大面板 |

### 4.2 缓动函数

```css
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);  /* 弹出效果 */
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);  /* 弹性效果 */
```

### 4.3 常用动画

| 名称 | 描述 | 时长 |
|------|------|------|
| `msgSlideIn` | 消息入场（上移+淡入） | 250ms |
| `welcomeIn` | Welcome卡片入场 | 500ms |
| `shimmer` | 渐变条流动 | 3s infinite |
| `float` | Logo浮动 | 3s infinite |
| `blink` | 打字指示器 | 1.2s infinite |
| `pulse` | 状态点脉冲 | 2s infinite |
| `cdPop` | 模态框弹出 | 200ms |

## 九、视觉对比

### 9.1 导航栏
```
旧设计：58px固定宽度，12个图标无标签
新设计：68px默认，悬停展开200px，图标+标签，渐变高亮

```


```
旧设计：固定高度，工具按钮拥挤
新设计：自动高度，悬停展开工具栏，聚焦高亮
```
