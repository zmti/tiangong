## 🎨 设计系统

### 1. 色彩系统

| 类型 | 色值 | 用途 |
|------|------|------|
| **Primary** | `#6366f1` | 主色调、品牌识别 |
| **Accent** | `#06b6d4` | 强调色、高亮提示 |
| **Success** | `#10b981` | 成功状态 |
| **Error** | `#ef4444` | 错误状态 |
| **Warning** | `#f59e0b` | 警告状态 |
| **Info** | `#3b82f6` | 信息提示 |

#### 背景层级
```
Level 0: --bg-base (#f1f5f9)     页面底色
Level 1: --bg-surface (#ffffff)  卡片/面板背景
Level 2: --bg-elev (#f8fafc)     悬浮元素背景
```

#### 文字层级
```
Level 1: --text-primary (#0f172a)    标题/重要内容
Level 2: --text-secondary (#475569)  正文内容
Level 3: --text-muted (#94a3b8)      次要信息
Level 4: --text-faint (#cbd5e1)      提示/占位符
```

### 2. 圆角体系

| 变量 | 值 | 适用场景 |
|------|-----|----------|
| `--radius-xs` | 4px | 图标按钮、标签 |
| `--radius-sm` | 8px | 小按钮、输入框 |
| `--radius-md` | 12px | 卡片、消息气泡 |
| `--radius-lg` | 16px | 大面板、弹窗 |
| `--radius-xl` | 24px | 容器、特殊组件 |

| `--shadow-md` | 0 4px 16px | 弹窗、下拉 |
| `--shadow-lg` | 0 8px 32px | 模态框、导航 |

### 4. 间距体系

| 变量 | 值 | 适用场景 |

## ✨ 动效设计

### 过渡动画

| 场景 | 时长 | 缓动函数 |
|------|------|----------|
| 面板展开/收起 | 250ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 按钮点击 | 150ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 消息出现 | 250ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 弹窗弹出 | 250ms | cubic-bezier(0.34, 1.56, 0.64, 1) |

### 微交互

- **按钮悬浮**: translateY(-1px) + 阴影增强
- **输入框聚焦**: 边框变紫 + 外发光
- **卡片悬浮**: translateY(-2px) + 阴影
- **消息悬浮**: 显示操作按钮
