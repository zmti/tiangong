## 🎨 设计令牌体系

### 色彩系统

| 类型 | 色值 | 用途 |
|------|------|------|
| Primary | `#6366f1` | 主色调，品牌识别 |
| Accent | `#06b6d4` | 强调色，高亮提示 |
| OK | `#10b981` | 成功状态 |
| Error | `#ef4444` | 错误状态 |
| Warn | `#f59e0b` | 警告状态 |
| Info | `#3b82f6` | 信息提示 |

### 背景层级

```
Level 0: --bg-base (#f1f5f9)     - 页面底色
Level 1: --bg-surface (#ffffff)  - 卡片/面板背景
Level 2: --bg-elev (#f8fafc)     - 悬浮元素背景
```

### 文字层级

```
Level 1: --text-primary (#0f172a)    - 标题/重要内容
Level 2: --text-secondary (#475569)  - 正文内容
Level 3: --text-muted (#94a3b8)      - 次要信息
Level 4: --text-faint (#cbd5e1)      - 提示/占位符
```

### 圆角体系

| 变量 | 值 | 适用场景 |
|------|-----|----------|
| `--radius-xs` | 4px | 图标按钮、标签 |
| `--radius-sm` | 8px | 小按钮、输入框 |
| `--radius-md` | 12px | 卡片、消息气泡 |
| `--radius-lg` | 16px | 大面板、弹窗 |
| `--radius-xl` | 24px | 容器、特殊组件 |

### 阴影体系

| 变量 | 值 | 适用场景 |
|------|-----|----------|
| `--shadow-xs` | 0 1px 2px | 微悬浮 |
| `--shadow-sm` | 0 2px 8px | 卡片悬浮 |
| `--shadow-md` | 0 4px 16px | 弹窗、下拉 |
| `--shadow-lg` | 0 8px 32px | 模态框、导航 |

## 🏗️ 布局系统

### 三栏布局

```
┌──────────────┬───────────────┬────────────────────────┬─────────────────┐
│              │               │                        │                 │
│   图标导航   │   会话列表    │       主聊天区          │    右侧面板     │
│   (64px)     │   (280px)     │        (flex: 1)       │   (440px)      │
│              │               │                        │                 │
│ • Logo       │ • 搜索框      │ • 消息列表             │ • 知识库        │
│ • 对话       │ • 会话列表    │ • 欢迎页               │ • 记忆管理      │
│ • 待办       │ • 新建/导出   │ • 输入区域             │ • 运行记录      │
│ • 知识库     │               │                        │ • 设置         │
│ • 记忆       │               │                        │                 │
│ • ...        │               │                        │                 │
│              │               │                        │                 │
└──────────────┴───────────────┴────────────────────────┴─────────────────┘
```

### 布局特性

- **响应式**: 支持桌面、平板、手机三种尺寸
- **可折叠**: 导航栏和会话栏可收起
- **可扩展**: 右侧面板可展开/收起
- **自适应**: 输入框宽度自适应

## 🧩 组件库

### 1. 导航组件

#### 图标导航栏
- 宽度: 64px (默认) / 200px (悬停展开)
- 高度: 100vh
- 动画: 平滑过渡 (250ms)
- 指示器: 左侧蓝色竖条

#### 会话列表
- 搜索: 带图标的搜索框
- 列表项: 标题 + 元信息 + 操作按钮
- 状态: 活跃、悬停、选中、置顶

### 2. 消息组件

#### 消息气泡
- 用户消息: 紫色渐变背景，右对齐
- AI消息: 白色背景，左对齐
- 边框圆角: 不对称设计 (右下角更小)

#### 消息操作
- 复制: 点击复制消息内容
- 重新生成: 重新生成AI回答
- 点赞/点踩: 反馈机制

#### 思考过程
- 可折叠的thinking区域
- 左侧紫色边框标识
- 点击展开/收起

### 3. 输入组件

#### Composer
- 圆角: 24px (全圆角)
- 焦点状态: 紫色边框 + 阴影
- 工具栏: 模型选择 + 模式选择 + 附件工具
- 快捷键: Enter发送, Shift+Enter换行

#### 模型选择器
- 下拉面板: 搜索 + 分组 + 速度标签
- 持久化: localStorage存储

#### 模式选择器
- 基础模式: 自动/快速/把关/择优
- 团队模式: 流水线/分工/擂台赛

### 4. 侧边面板

#### 知识库
- 拖拽上传: 虚线边框区域
- 文件列表: 图标 + 名称 + 操作
- 统计信息: 文档数 + 片段数

#### 长期记忆
- 搜索过滤: 关键词 + 作用域
- 记忆列表: 内容 + 标签 + 操作
- 添加表单: 文本 + 关键词

#### 运行记录
- 时间线视图: 按时间排序
- 状态标识: 成功/失败/运行中
- 详情展开: 点击查看详情

#### 用量统计
- Token使用: 柱状图/折线图
- 成本追踪: 按天/按会话
- 趋势分析: 同比/环比

### 5. 模态框

#### 确认对话框
- 居中显示
- 遮罩层: 半透明 + 模糊
- 动画: 弹出效果 (spring easing)

#### 通知Toast
- 位置: 右下角
- 类型: 成功/错误/警告/信息
- 自动消失: 3秒后淡出

## ✨ 动效设计

### 过渡动画

| 场景 | 时长 | 缓动函数 |
|------|------|----------|
| 面板展开/收起 | 250ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 按钮点击 | 150ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 消息出现 | 250ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 弹窗弹出 | 250ms | cubic-bezier(0.34, 1.56, 0.64, 1) |

### 微交互

- 按钮悬浮: translateY(-1px) + 阴影增强
- 输入框聚焦: 边框变紫 + 外发光
- 卡片悬浮: translateY(-2px) + 阴影
- 消息悬浮: 显示操作按钮

## 📱 响应式断点

| 断点 | 设备 | 调整策略 |
|------|------|----------|
| > 1024px | 桌面 | 完整布局 |
| 768-1024px | 平板 | 侧边栏压缩 |
| < 768px | 手机 | 全屏模式 + 抽屉导航 |
| < 480px | 小屏手机 | 简化布局 |
