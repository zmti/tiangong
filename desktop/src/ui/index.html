生成模型

图片 / 视频生成调用哪个模型。候选来自「模型设置」里带对应能力的模型, 选择即覆盖 .env 配置,保存后立即生效、无需重启。
生成模型没有专门配置时,若当前对话所用的模型本身就支持该能力(多模态模型), 会直接跟着对话模型走;也可以显式选「跟随对话模型」。
右侧开关关闭后不使用上面选的模型,改用当前对话所用的模型来生成 —— 生成能力本身不受影响,AI 依然能出图 / 出片。
